# Cart and date-based orders

Build `/cart` using the existing persisted Zustand cart, cream/brown theme, and responsive components. Collect customer name and LINE ID above the list. Group items chronologically by `pickupDate`; each distinct date becomes one Firestore `orders` document with the same customer details. Delivery remains subject to LINE confirmation.

1. Add checkout validation and a shared grouping function. Test three dates, duplicate quantities, empty customer fields, and unavailable dates.
2. Add a transactional order service and POST endpoint. Read authoritative product prices, save all date groups atomically, and reuse a request ID on retries. Test server pricing, missing products, retries, and failed commits.
3. Add cart removal/clearing with persistence error rollback. Build the customer form, grouped item list, per-date totals, submit action, empty/loading/error/success states, and navbar/product-page links.
4. Run all existing and new tests, render checks, and TypeScript checking. Do not submit real orders during verification.

No new dependencies or payment integration. Never clear the cart on a failed submission. Preserve unrelated workspace changes.
